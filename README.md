# Мастер бровей & ресниц

Портфолио мастера Евгении Ванюшовой. Страница собрана на React, TypeScript, Vite и Tailwind CSS.

## Запуск

```bash
npm install
npm run dev
```

## Проверки и сборка

```bash
npm test
npm run lint
npm run build
npm run preview
```

## Структура

- `src/components/` — секции страницы и карточки.
- `src/data/portfolio.ts` — заголовки, описания и изображения галерей. Секция «До и После» выводит все записи; допускается 3, 4 или 6 фотографий.
- `src/data/contacts.ts` — номер телефона и почта для первого экрана и футера.
- `src/assets/` — фотографии портфолио и сравнений.
- `src/index.css` — стили и дизайн-токены.
- `tests/app.test.mjs` — проверки рендера страницы и галерей.
- `DESIGN_SOURCE.md` — источник дизайна и актуальные технические требования.
